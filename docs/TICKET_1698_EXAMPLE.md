- **建议回复直译**：生成建议回复后，将回复正文按客服偏好语言做直译，显示在此处，便于中文客服理解日文/英文回复内容。
- **回复要点**（下列表）：

**应输出示例**（中文）：

- 确认已收到「转接人工」的请求，并说明将由人工客服跟进。

## 5. 建议回复（生成回复框）

**位置**：「建议回复」→ 点击「生成回复」后出现在文本框中的内容。

**规则**：建议回复必须使用**用户原始语言**（本工单客户用日文，故回复为日文；若客户用英文则回复英文）。

**应输出示例**（日文，因对话为日文且 Comulytic 客服面向该用户使用日文）：

```
お問い合わせありがとうございます。オペレーターへのご転送のご要望、承知いたしました。

こちらの事案はサポートチームが引き継ぎ、24時間以内にアプリ内通知またはメールにてご返信いたします。よりスムーズにご対応するため、以下をご記載いただけると幸いです：
・お使いのデバイスのシリアル番号
・アプリのバージョン
・電源が入らないときの状況（充電の有無、ボタン操作の様子など）

ご不便をおかけし申し訳ございません。何卒よろしくお願いいたします。
```

**说明**：

- 人设：专业、同理心，不暴露 AI 身份。
- 信息对齐：确认「转接人工」已收到，并再次索要设备信息（与客服前一条消息一致但不重复冗长）。
- 无 URL、无诱导评论（尤其若 tags 含 amazon）。
- 若 RAG 带出设备状态（如 SN、电量、AI 余额），可在回复中自然引用；若 AI 余额为 0，需引导充值。

## 数据流小结

| 模块 | 数据来源 | 输出形态 |
|------|----------|----------|
| 紧急程度 | 后端 `/evaluate-priority`（subject + description + tags） | P0/P1/P2/P3 + reason 一句 |
| 最后一条会话 | Zendesk 当前工单 comments，取最后一条客户消息 | 原文 + 翻译（`/translate`） |
| 工单总结 + 回复要点 | 后端 `/summarize`（工单全文 + 偏好语言） | summary 文本 + replyPoints 文本 |
| 建议回复 | 后端 `/suggest-reply`（context + RAG + 设备状态 + tags） | 纯回复正文，日/英/中按需 |
| 提示词 | 侧栏输入框 | 拼入 suggest-reply 的 agentInstruction |
