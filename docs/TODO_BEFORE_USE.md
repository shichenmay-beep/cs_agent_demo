# 距离能用 — 待办列表

按「能真正在 Zendesk 里用起来」整理，从上到下按顺序做即可。

---

## 必做（不做就不能用）

| # | 事项 | 怎么做 |
|---|------|--------|
| 1 | **后端部署到公网并开 HTTPS** | 把 `backend/` 部署到境外服务器或云函数（香港/新加坡等，见 [DEPLOYMENT_SPEC.md](./DEPLOYMENT_SPEC.md)）；提供 HTTPS 地址。若必须国内部署，需改接国产大模型 API。 |
| 2 | **配置大模型密钥** | 在运行环境设置 `OPENAI_API_KEY`（OpenRouter 时再设 `OPENAI_API_BASE`、`OPENAI_MODEL`）。勿把真实 key 提交到仓库。 |
| 3 | **在 Zendesk 安装 App** | 项目根目录执行 `zcli apps:pack` 打 zip，在 Zendesk Admin → Apps 里上传安装。 |
| 4 | **配置 backend_url** | 安装/编辑该 App 时，把 **backend_url** 填成第 1 步的后端 HTTPS 地址。 |
| 5 | **替换真实 FAQ** | 把 `product_docs/faq.json` 换成你们真实产品话术与政策（或接入内部知识库）。 |
| 6 | **在真实 Zendesk 上跑通一遍** | 打开一条工单 → 侧栏能加载 → 优先级、翻译、总结、建议回复、展开/收起、使用并发送或填入回复框，整条链路无报错。 |

## 测试阶段：防止误发真消息

- **两种方式**：  
  - **填入回复框**：仅将文案填入 Zendesk 回复框，**不会发送**；客服可在 Zendesk 中编辑后再点「提交」。  
  - **一键发送**：直接调用 Zendesk API 提交公开回复，**会真正发信给客户**；点击前有二次确认「发送后无法撤回」，请确认内容后再点。
- **界面**：建议回复区域有黄色提示，说明「填入」可编辑后提交、「一键发送」会直接发送。
- **二次确认**：「填入」与「一键发送」操作前均有确认框，避免误触。
